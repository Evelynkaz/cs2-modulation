# cs2-modulation

Калькулятор раскидок (lineups) для CS2 на Rust: по точке на карте находит
все броски smoke/flash/HE/molotov/incendiary/decoy, выдаёт
`setpos …; setang …`, тип броска (stand, walk, run, crouch, jump, run-jump),
клик, траекторию, точку приземления и стабильность. Веб-вьювер даёт
2D-радар и 3D-сцену коллизий.

## Запуск

Собрать один раз (Windows, из PowerShell или cmd — см. «Сборка» ниже):

    scripts\cargo-msvc.cmd build --release -p cs2mod-cli

Запустить `target\release\cs2mod.exe` двойным кликом (или без аргументов из
консоли) — это то же, что `cs2mod serve --open`: поднимается локальный сервер
на `http://127.0.0.1:8137/` (только loopback) и открывается браузер. Окно
консоли — это сервер; закрыли окно или нажали Ctrl-C — сервер остановлен.
Другой порт: `cs2mod serve --port <N> --open`.

1. **Первый запуск** — указать папку CS2 (корень установки или `…\game\csgo`),
   программа проверит её и покажет билд игры. Папка кэша необязательна (по
   умолчанию `cache\` в корне репозитория). Настройки хранятся в
   `%APPDATA%\cs2-modulation\config.json`.
2. **Карты** — список карт со скриншотом загрузочного экрана из самой игры
   и тегом режима (Обезвреживание/Заложники/Гонка вооружений);
   «Подготовить» по карте запускает цепочку: извлечение коллизий → точки
   стояния → радар → 3D-модель (всё кэшируется, прогресс и отмена прямо в
   списке). Новую карту можно извлечь по имени (`de_mirage`).
3. **Экран карты** — три шага слева, карта посередине, результаты справа.
   **1 Куда бросить** — точка (клик), область падения («граната упала где
   угодно в области») или «Перекрыть обзор» (клик, откуда смотрит
   противник, затем — куда; ищутся смоки, чей дым перекрывает этот
   обзор). **2 Откуда бросать** — вся карта, спавны, точка или обведённая
   область (при многоэтажности — выбор этажа/высоты), плюс «Упор»: Любой /
   У стены / В углу. **3 Граната и бросок** — пока только смок; тип
   броска — Стоя / Присев / Прыжок / Присев + прыжок (броска с разбегом в
   интерфейсе нет — его нельзя повторить без тайминга разбега).
   Карта: 2D — официальный радар игры (с переключателем этажей на
   многоуровневых картах вроде Nuke), поверх которого кнопкой «Схема»
   включается наша схема коллизий; 3D — текстурированная карта с
   освещением как в игре. Клики по полу или крыше в 3D ставят вершины
   области, беря высоту из места клика; Shift+ЛКМ ставит точку броска;
   кольцо под курсором показывает высоту и место под ним.
   Результаты справа: сложность (Лёгкая/Средняя/Сложная — по устойчивости
   прицела к погрешности и запасу до срыва, не по грубому разбросу),
   пошаговая инструкция на русском, «Скопировать» — точная проверенная
   команда `setpos …; setang …` (безопасный телепорт, без проваливания в
   мир), «Вид игрока» и три картинки, собранные по 3D-карте: прицел с
   увеличенной вставкой, где встать и куда упадёт.

Программа читает только файлы игры на диске и никак не взаимодействует с
запущенной игрой.

## Проверка в игре

Скопированную кнопкой «Скопировать» команду (точные значения, безопасный
телепорт) можно проверить на локальном практис-сервере:

```
map de_mirage              # или нужная карта
sv_cheats 1; mp_warmup_end; mp_freezetime 0; mp_roundtime_defuse 60; mp_restartgame 1; sv_infinite_ammo 1; ammo_grenade_limit_total 5; bot_kick
give weapon_smokegrenade
setpos …;setang …          # вставить скопированную строку, дождаться приземления
```

бросок — как написано в инструкции раскидки; «прыжок» — это обычный бросок в
прыжке без биндов: зажать ЛКМ, нажать прыжок и сразу отпустить ЛКМ (бинды
jumpthrow в CS2 с августа 2024 не работают, а ручной бросок в прыжке игра
делает стабильным). Чтобы
прислать нам демку с расхождением для разбора, GOTV пишется так:

```
tv_enable 1;tv_delay 0     # ДО загрузки карты, потом map <карта>
tv_record <имя>            # перед броском
tv_stoprecord              # после броска
```

файл `<имя>.dem` окажется в `game\csgo`.

## Статус

Этапы 0–3 сделаны: скелет workspace, документы, CI, VPK, контейнер
ресурсов и KV3 (`s2fmt`), физика, entity lump'ы, world node'ы, `.nav` и
извлечение геометрии карты (`extract`), а также геометрические запросы —
`UniformGrid`, `Bvh`, `VoxelGrid` (`geom`). Для разработки доступны команды
`cs2mod vpk
ls|cat|verify` (например, `cs2mod vpk ls pak01_dir.vpk`), `cs2mod res
[--vpk] [--block] [--kv3]` (например, `cs2mod res world_physics.vmdl_c
--kv3`), а также:

```
cs2mod extract de_mirage
cs2mod info de_mirage
cs2mod export-obj de_mirage --filter grenade --out cache/obj/de_mirage_grenade.obj
```

Этап 4b добавил симуляцию броска/дыма/линии видимости и офлайн-инструменты
калибровки:

```
cs2mod throw de_mirage --pos 500,-800,-160 --ang -10,45 --type jump
cs2mod smoke de_mirage --rest -500,-1400,250 --params full
cs2mod sightline de_mirage --from ... --to ... --rest ...
cs2mod replay --all                       # весь корпус validation референса
cs2mod calibrate de_mirage --throws data/throws.json --unfreeze speed,jumpv
```

Этап 5 добавил обратный поиск раскидок (`solver`) и его CLI:

```
cs2mod standspots de_mirage                # кэширует standspots.json (реальный хулл игрока)
cs2mod solve de_mirage --target -662.5,-1612.5 --from -104.5,-1796 --reach 600 --tolerance 32
    # 2945 верифицированных раскидок, побитово сверено с референсом (parity harness)
cs2mod solve de_mirage --target -662.5,-1612.5,-172 --exact --from 32,-1696 --referee
cs2mod solve de_mirage --target -662.5,-1612.5 --json cache/a-site.json
```

`solve` резолвит `--target`/`--from`/`--getpos` (пасте getpos'а: с `setang` —
это EYE, feet = eye − (0,0,64.06); без `setang` позиция уже feet, как в
вьюере `main.js`/`state.js`, а не безусловное `eye − 64` как в
`ValidateCommand.cs`), собирает воксельную сетку и коллайдеры региона
(с `MeshSetup.cs:SingleTargetDefaultAttrs` = `Default,default,EntitySolid`;
`EntitySolid` тянет `EntityDoor`/`EntityBreakable`), собирает origins (кэш
`standspots.json`, иначе стойки с nav-área — с подсказкой запустить
`standspots`, если кэша нет или он устарел), проходит грубым перебором по
углам (`sweep`), точной проверкой с шевелением прицела (`verify`), при
пустом точном спуске (`--exact`) — исчерпывающим перебором и эскалацией
2°→1°, затем ранжирует результат (`LineupApi.cs:Rank`) и печатает топ
`--top` строк плюс, по `--json`, полный список в формате JSON-полей
референса (`id`, `feet`, `yaw`, `pitch`, `how`, `rest`, `Bounces`,
`stability`, `humanError`, `aimRef`, `coverage`, `console`, …).
`--reach` по умолчанию 300u при `--from`/`--getpos`, иначе 3100u (весь
уровень) — как в `LineupApi.cs`'s `RunTargetQuery`.

Константы броска (`ThrowConstants`) по умолчанию берутся из `sim`; если
рядом лежит `data/throw-constants.json` (или передан `--constants <path>`),
он подхватывается автоматически, о чём печатается строка `throw constants:
<path>` — как у референса (`MeshSetup.cs:LoadConstants`). `calibrate` по
умолчанию ничего не подбирает: все константы заморожены (`physics-sim.md`
референса называет измеренными и `ThrowSpeed`, и клики, и `JumpVelocity` —
неконтролируемый фит по броскам однажды испортил гравитацию до `0.34`);
подбор конкретной константы включается явно через `--unfreeze
speed,jumpv,...`, и `--out` по умолчанию пишет в `data/throw-constants.json`
(`config/` отклонит guard записи — это каталог не для игровых/калиброванных
данных). Коды возврата (как у референса):

| Команда | `0` | `2` | иначе |
|---|---|---|---|
| `throw` | бросок долетел | `result.lost` | — |
| `smoke` | объём дыма не пуст | объём дыма пуст | — |
| `sightline` без `--rest` | геометрия не блокирует | геометрия блокирует | — |
| `sightline` с `--rest` | `NOT blocked by smoke` | `BLOCKED by smoke` (`smoke_cells_crossed >= 3`, независимо от точной геометрии) | — |
| `replay` | — | — | `1`, если не нашлось ни одного зачётного броска |

Этап 6 добавил локальный сервер (`cs2mod serve`, см. «Запуск») и веб-вьювер:
2D-радар и текстурированную 3D-карту с запечённым освещением, 3D-скайбоксом
и эффектами `csgo_effects` (пыль, облака, свечения) как в игре, области
«откуда бросать» и области цели, точную стабильность (раскидки, рассчитанные
на прицеливание по точке, ±0,2°, при этом ранжирование учитывает старый
запас ±0,6°), поиск только из угла или у стены, официальные радары и
скриншоты карт из файлов игры (читаются только локально), а также
`cs2mod export-glb <map>` (экспортирует 3D-модель в кэш карты; обычно
запускается кнопкой «Подготовить»).

Разбор реальных бросков (GOTV-демка пятерых бросков на Mirage) показал:
экстрактор коллизий мёржил func_brush с solidity «Never Solid» как
сплошную стену, хотя гранаты в игре сквозь них пролетают (57 из 70 таких
брашей на 11 из 23 карт) — исправлено, демка стала регрессионным тестом
(расхождение с игрой ≤ 0,16u). Точный режим прицеливания теперь центрирует
угол в его рабочей области (решётка 13×13, шаг 0,05°) и считает
устойчивость (`robustness`) по прицелу, ногам ±1u и модели запуска, а не
по пяти пробам вокруг выбранного угла (по ней же теперь и сложность);
«Скопировать» отдаёт точную проверенную команду вместо округлённой, а
`setpos` проверяется и при необходимости сдвигается на ≤2u, чтобы не
поставить хулл игрока в наклонную стену. Цель поиска — ещё и «Перекрыть
обзор»: по двум точкам (откуда и куда смотрит противник) находятся смоки,
чей дым перекрывает эту линию видимости.

Подробности и текущее состояние — в [`PROGRESS.md`](PROGRESS.md).

## Жёсткие правила

- Никаких файлов игры в git: `data/` и `cache/` — в `.gitignore`.
- Никакого взаимодействия с запущенной игрой — только файлы на диске.
  Проверка бросков — вручную, на локальном практис-сервере через
  `setpos`/`setang`.
- Любая физическая константа — со ссылкой на источник в комментарии или
  пометкой `TODO: calibrate`.

## Структура

| Крейт / каталог | Назначение |
|---|---|
| `crates/s2fmt` | Форматы Source 2: VPK, контейнер `*_c`, KV3 (binary/text), физика, entity lump'ы, world nodes, CS2 `.nav`. Чистый парсер без знаний о геймплее CS2. |
| `crates/geom` | Геометрия коллизий: `TriMesh` с атрибутами на треугольник, фильтры атрибутов, BVH (raycast/sweep), воксельные сетки, экспорт в OBJ. |
| `crates/extract` | Политика извлечения карты CS2: мёрж world physics, твёрдых brush-энтити, статических пропов и бьющегося стекла в один меш коллизий; кэш по хешу .vpk карты и версии экстрактора. |
| `crates/sim` | Потиковая симуляция гранаты (тик 1/64с, 2 физических подшага), детонация по типу гранаты, объём дыма и линии видимости. |
| `crates/solver` | Обратный поиск раскидок: standspots, грубый перебор по вокселям, уточнение, точная проверка с шевелением прицела, оценка стабильности, ранжирование. |
| `crates/calib` | Калибровка констант броска по замерам (`throws.json`, совместим с cs2-smoke-solver) и офлайн-replay корпусов бросков. |
| `crates/radar` | Растровый радар карты сверху (PNG) и заголовок `viewer-map.json` для 2D-экрана вьювера. |
| `crates/s2render` | Экспорт видимой геометрии рендера, материалов, освещения и 3D-скайбокса в `render.glb`/`render.json` для вьювера. |
| `crates/s2tex` | Декодирование текстур CS2, включая BC-сжатие и HDR. |
| `crates/server` | HTTP API (axum) и статика веб-вьювера, долгие задачи solve с прогрессом. |
| `crates/cli` | CLI `cs2mod` (clap): extract, info, throw, solve, standspots, calibrate, replay, serve, export-obj, export-glb и другие команды. |
| `viewer/` | Веб-вьювер без сборщика (ES-модули + вендоренный three.js в `viewer/lib`): 2D-радар, 3D-карта с текстурами и освещением, выбор областей и результаты поиска. |
| `config/` | Конфиги и переопределения констант. |
| `docs/` | Документация: архитектура и форматы файлов. |
| `scripts/` | Вспомогательные скрипты сборки. |

## Сборка

Требуется Rust, закреплённый в `rust-toolchain.toml` (1.98.1, `edition = "2024"`);
`rustup` подхватит его автоматически.

```
cargo build --workspace
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all --check
```

Windows: если `rustc` не находит `link.exe` (например, с Visual Studio 2026 /
VS 18), собирайте через `scripts\cargo-msvc.cmd <args>`. В Git Bash
`/usr/bin/link.exe` перекрывает MSVC-линкер — собирайте из PowerShell или cmd.

## Путь к игре

Вьювер берёт папку игры с экрана первого запуска (сохраняется в
`config.json`); CLI-команды — из `--game` или переменной `CS2_GAME_DIR`
(`…\steamapps\common\Counter-Strike Global Offensive\game\csgo`). В
репозиторий путь не пишется.
